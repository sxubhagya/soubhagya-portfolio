# Soubhagya Daspattanayak - Portfolio

Personal portfolio website built with React, Vite, TypeScript, and Tailwind CSS, featuring bespoke typography (Banto Medium & Helvetica Now Display) and exact aesthetic visual composition.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🛠 Tech Stack
- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Typography**: Banto Medium (`assets/fonts/`), Helvetica Now Display
- **Assets**: Handcrafted stickers & ASCII art (`assets/stickers/`, `public/stickers/`)
